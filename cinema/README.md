# КиноБиблиотека

Личный агрегатор фильмов с рандомайзером. Telegram Mini App — авторизация через Telegram,
без паролей. Каждый, кто открывает бота, получает свой профиль; библиотека фильмов общая,
статус просмотра и оценка — у каждого свои.

Стек: Next.js 16 (App Router) + Prisma + PostgreSQL, метаданные фильмов — TMDB API.

## Возможности

- Добавление фильма поиском по TMDB (постер, описание, жанры, год, рейтинг подтягиваются автоматически)
- Статус по фильму: буду смотреть / смотрю / посмотрено — свой у каждого профиля
- Личная оценка (1–10) после просмотра
- Рандомайзер: случайный выбор фильма с фильтром по жанру и опцией «не показывать посмотренные»

## Локальная разработка

```bash
cp .env.example .env
npm install
npx prisma db push
npm run dev
```

Приложение работает только внутри Telegram (использует `window.Telegram.WebApp.initData` для
входа), поэтому для локальной проверки вне Telegram потребуется либо туннель (ngrok/cloudflared)
и тестовый бот, либо подмена `window.Telegram` в консоли браузера.
