# Деплой на Coolify

Код лежит в подпапке `cinema/` в том же репозитории, что и `lystra-portal`, но разворачивается
как отдельный сервис — со своим доменом, своей базой (новая БД в существующем Postgres) и своим
Telegram-ботом.

## 1. TMDB API-ключ

1. Зарегистрируйтесь на https://www.themoviedb.org/ (если ещё нет аккаунта).
2. Перейдите в Settings → API → Create → выберите "Developer" → заполните форму (можно указать
   "personal project").
3. Скопируйте **API Key (v3 auth)** — это и есть `TMDB_API_KEY`.

## 2. Telegram-бот

У вас уже есть токен бота. Осталось привязать к нему Mini App:

1. Напишите @BotFather → `/mybots` → выберите бота.
2. **Bot Settings → Menu Button → Configure menu button** — укажите URL приложения (домен, который
   вы дадите сервису в Coolify, например `https://cinema.вашдомен.ру`) и текст кнопки, например
   "Открыть".
   - Домен должен быть доступен по HTTPS — Coolify обычно выпускает сертификат сам через Let's Encrypt.
3. Готово: при нажатии кнопки в чате с ботом откроется приложение как Mini App.

## 3. База данных

В Coolify найдите уже существующий Postgres-ресурс (тот, что использует `lystra-portal`) и
создайте в нём отдельную базу для этого приложения, не трогая существующие таблицы портала:

```sql
CREATE DATABASE cinema;
```

Выполнить можно через встроенный терминал/консоль ресурса в Coolify либо подключившись `psql`
снаружи. Получите строку подключения вида:

```
postgresql://<user>:<password>@<internal-host>:5432/cinema
```

(хост обычно внутренний, вида `postgres` или имя контейнера — уточните в настройках существующего
Postgres-ресурса в Coolify; используйте тот же хост/пользователя, что и у lystra, просто с именем
базы `cinema`).

## 4. Сервис в Coolify

1. **New Resource → Application → Public/Private Git Repository** (тот же репозиторий, что и
   lystra-portal, та же ветка/main после мёржа).
2. **Base Directory**: `cinema` (важно — сервис лежит в подпапке, не в корне репозитория).
3. **Build Pack**: Nixpacks (автоопределение Next.js) — Dockerfile не нужен.
4. **Port**: `3000`.
5. **Environment Variables** — добавьте:
   - `DATABASE_URL` — строка подключения из шага 3
   - `AUTH_SECRET` — случайная строка (сгенерировать: `openssl rand -base64 32`)
   - `TELEGRAM_BOT_TOKEN` — токен вашего бота
   - `TMDB_API_KEY` — ключ из шага 1
6. **Domain**: привяжите домен/поддомен, который вы указали в BotFather (шаг 2).
7. Нажмите **Deploy**.

Скрипт сборки (`npm run build`) сам выполнит `prisma generate && prisma db push && next build` —
таблицы в новой базе создадутся автоматически при первом деплое, отдельные миграции запускать не
нужно.

## 5. Проверка

Откройте бота в Telegram, нажмите кнопку меню — должна открыться библиотека фильмов (пустая при
первом запуске). Добавьте первый фильм через поиск TMDB и проверьте, что рандомайзер его находит.

Если вместо приложения видите ошибку "Откройте приложение через Telegram-бота" — значит страница
открыта не изнутри Telegram (например, напрямую в браузере) или `TELEGRAM_BOT_TOKEN` не совпадает
с ботом, через который открывали.
